### Auto-Generated scripts/orchestrate.py (SSP protocol)

```python
# [TỪ BA §1.1 S1, FR-15, design.md §2.5 — orchestrator exception]
# Generated by skill-builder Phase 3 if SCS >= 3.0
# SSP = State & Signal Protocol — shared state files between sub-skills

import os
import json
from pathlib import Path

class PipelineOrchestrator:
    """
    Orchestrates extract -> transform -> load sub-skills via SSP.
    State is shared via .ssp/state.json file.
    """
    def __init__(self, ssp_state_dir: str = ".ssp"):
        self.ssp_dir = Path(ssp_state_dir)
        self.ssp_dir.mkdir(exist_ok=True)
        self.state_file = self.ssp_dir / "state.json"

    def load_state(self) -> dict:
        if not self.state_file.exists():
            return {"phase": "init", "sub_skill": None, "status": "pending"}
        return json.loads(self.state_file.read_text())

    def save_state(self, state: dict) -> None:
        self.state_file.write_text(json.dumps(state, indent=2))

    def run_pipeline(self) -> bool:
        sub_skills = ["data-pipeline-extract", "data-pipeline-transform", "data-pipeline-load"]
        for sub in sub_skills:
            state = self.load_state()
            state["sub_skill"] = sub
            state["phase"] = "running"
            state["status"] = "in_progress"
            self.save_state(state)

            # Invoke sub-skill (caller does the actual sub-skill execution)
            success = self.invoke_sub_skill(sub, state)

            state["status"] = "success" if success else "failed"
            if not success:
                state["phase"] = "halted"
                self.save_state(state)
                return False

        state = self.load_state()
        state["phase"] = "complete"
        state["status"] = "success"
        self.save_state(state)
        return True

    def invoke_sub_skill(self, sub_skill_name: str, state: dict) -> bool:
        """
        Pure I/O — reads .ssp/state.json, runs sub-skill CLI, writes result.
        NO domain decisions (per knowledge/skill-builder-script-boundary-policy.md).
        """
        import subprocess
        sub_skill_path = Path(sub_skill_name)
        skill_md = sub_skill_path / "SKILL.md"
        if not skill_md.exists():
            return False
        # Caller decides which sub-skill to run; orchestrator only wires state.
        return True

    success = orchestrator.run_pipeline()
    sys.exit(0 if success else 1)
```

## Common Anti-Patterns (across both examples)

❌ **Don't**: Create README.md, LICENSE, Makefile — these are NOT in design.md §3
✅ **Do**: Trust design.md §3 as contract; add files ONLY if listed

❌ **Don't**: Embed high-level decisions in scripts/orchestrate.py
✅ **Do**: Scripts do IO + state passing; caller (AI agent) makes decisions

❌ **Don't**: Copy entire design.md into SKILL.md
✅ **Do**: SKILL.md = L0 anchor; reference design.md + policy/ for details

❌ **Don't**: Skip validation because "code looks correct"
✅ **Do**: Run validate_skill.py + build-checklist.yaml at Phase 4; gate on Exit 0
